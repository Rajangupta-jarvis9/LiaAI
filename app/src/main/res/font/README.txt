Download the following OFL-licensed fonts from Google Fonts and place the TTF files here.
NovaTokens.kt will pick them up automatically.

Instrument Serif  — https://fonts.google.com/specimen/Instrument+Serif
  instrument_serif_regular.ttf
  instrument_serif_italic.ttf

Manrope (variable or static weights)  — https://fonts.google.com/specimen/Manrope
  manrope_regular.ttf      (weight 400)
  manrope_medium.ttf       (weight 500)
  manrope_semibold.ttf     (weight 600)
  manrope_bold.ttf         (weight 700)
  manrope_extrabold.ttf    (weight 800)

Until the files are added the app compiles fine — NovaTokens.kt catches the
missing-resource exception and falls back to system serif / sans-serif.
